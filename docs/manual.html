1. Overview

lillardhaz fits a two-equation simultaneous model of the kind introduced by Lillard (1993): a pair of processes, each either a binary probit outcome or a continuous-time hazard duration, linked through a single correlation parameter rho between their underlying error terms and estimated jointly by maximum likelihood via a Gaussian copula.

Four families of model are supported, selected by the eq1/eq2 arguments of fit_lillardhaz():

eq1eq2Typical use
probitlognormala binary decision correlated with a log-normal AFT duration (e.g. Waite & Lillard 1991)
lognormallognormaltwo correlated log-normal AFT durations
probitpgompertza binary decision correlated with a flexible piecewise-Gompertz duration
pgompertzpgompertztwo correlated piecewise-Gompertz durations

Every combination can also be fit with corr=False, which restricts rho=0 and — as shown in Section 5 — reduces algebraically to two independent univariate fits, giving a natural nested baseline for a likelihood-ratio test of correlation.

Companion packages implementing the identical models: a Stata command and an R package, along with a from-scratch Python/R/Stata toolkit for the underlying (univariate) split-population survival models at github.com/nobifukuda/splitpopsurv.

2. The model

Each equation has a location index built from covariates, theta = Xb. For a probit equation, Y=1 iff theta + u > 0 with u ~ N(0,1); the latent index theta is itself standard-normal-scaled and so is already a copula residual. For a hazard equation, timing follows either:

  • log-normal: log(T) = theta + sigma·e, e ~ N(0,1) — the standard accelerated failure-time form; or
  • piecewise Gompertz: log h(t) piecewise linear in t (Section 3).

For any hazard equation, define the copula residual via the probability integral transform:

z = Phi-1( 1 - S(t) )

which is exactly standard normal under the fitted model, by construction, regardless of which timing distribution generated S(t). This is what lets a log-normal equation be paired with a piecewise-Gompertz equation under the same copula machinery.

3. Piecewise Gompertz timing

The piecewise Gompertz hazard (Lillard 1993, following his footnote 6) makes the log-hazard a continuous, piecewise-linear function of time. Given K-1 interior nodes 0 < n1 < ... < nK-1 (set by nodes1/nodes2, defining K segments) and per-segment slopes s1,...,sK:

log h(t) = theta + Lk + sk·(t - nk-1)   for t in segment k

where Lk is built recursively (L1=0, Lk+1 = Lk + sk·(nk-nk-1)) so the log-hazard has no jumps at the nodes. Because each segment's hazard is exp(linear), the cumulative hazard has a closed form on each segment (integrate exp(a+bx) analytically, with a linear-in-t fallback when a segment's slope is numerically zero), so S(t) = exp(-H(t)) and f(t) = h(t)S(t) require no numerical integration at any stage. This is implemented once, for a general number of segments, as _pgompertz_sf() in models.py and shared by both equations — a direct vectorized (numpy) port of the same recursion used in the R and Stata companion packages.

nodes1/nodes2 are literal duration time values you choose, not a segment count. Each entry is the actual time point where the hazard's slope is allowed to change — there is no auto-spacing, equal-interval, or quantile-based placement. K is simply derived from how many values you list (listing 3 nodes gives 4 segments; 1 node gives 2). For example, to place breakpoints at t=2, t=6, and t=15 (4 segments): 
fit = fit_lillardhaz(
    "pgompertz", "pgompertz", data,
    y1="time1", d1="event1", y2="time2", d2="event2",
    x1=["x1"], x2=["x2"], nodes1=[2, 6, 15], nodes2=[4],
)
A piecewise Gompertz segment with a negative slope has a hazard that decays toward 0, so its cumulative hazard is bounded as t → ∞ within that segment — the model is then a genuinely defective distribution (S(∞) > 0), the same way a Gompertz hazard with a negative shape parameter behaves in the univariate case. If you simulate data from such a model, a small fraction of draws may have no finite failure time reachable in floating point; treat those as always-censored (see tests/test_models.py for a worked example).

4. The joint likelihood, case by case

Write a = sqrt(1-rho2). When both equations are hazards, with residuals (z1,z2) and marginal density/survival (f1,S1,f2,S2):

both observed

phi2(z1,z2;rho) / (phi(z1)phi(z2)) · f1·f2

1 observed, 2 censored

f1 · ( 1 - Phi((z2-rho·z1)/a) )

1 censored, 2 observed

f2 · ( 1 - Phi((z1-rho·z2)/a) )

both censored

Phi2(-z1,-z2;rho)

When equation 1 is a probit (outcome y1, index theta1) and equation 2 is a hazard (residual z2, density/survival f2/S2):

y1=1, obs 2 observed

f2 · Phi((theta1+rho·z2)/a)

y1=1, obs 2 censored

Phi(theta1) - Phi2(theta1,z2;-rho)

y1=0, obs 2 observed

f2 · Phi(-(theta1+rho·z2)/a)

y1=0, obs 2 censored

Phi2(-theta1,-z2;-rho)

Phi2(·,·;rho) is the bivariate normal CDF, computed via scipy.stats.multivariate_normal(...).cdf(...) (cross-checked against the closed-form value Phi2(0,0;rho) = 1/4 + arcsin(rho)/(2*pi) to machine precision). The censored-cell formulas follow the inclusion-exclusion identity P(Z1>z1,Z2>z2) = 1-Phi(z1)-Phi(z2)+Phi2(z1,z2;rho) = Phi2(-z1,-z2;rho).

5. Independence and the corr=False reduction

Setting rho=0 gives a=1, and every formula above factors exactly into the product of the two marginal terms — e.g. the both-observed hazard×hazard cell becomes phi(z1)phi(z2)·f1·f2/(phi(z1)phi(z2)) = f1·f2, and the both-censored cell becomes Phi(-z1)Phi(-z2) = S1·S2. This is exactly Lillard's own identification result: with no correlation, the joint likelihood is the product of two independent univariate likelihoods. fit_lillardhaz(..., corr=False) fits this restricted model using the same likelihood function (with rho fixed at 0 and no atanh_rho parameter) rather than a separate code path.

6. A correction relative to the original templates

The widely-circulated ml templates this package's Stata/R/Python siblings all supersede generally build the joint bivariate density by inverting (1-rho2) into the wrong term of the exponent, or by mixing marginal density where a marginal hazard was intended (the same class of error documented for the univariate case in the companion splitpopsurv package). This package derives each of the eight branches in Section 4 directly from the bivariate normal density/CDF and the definition of the copula residual, and verifies every branch by simulation (Section 7) rather than by inspection alone.

7. Verification

Every eq1×eq2 combination, correlated and independent, was verified by simulating data under known parameters (the same data-generating processes as the R and Stata companion packages' test suites) and confirming fit_lillardhaz() recovers them; see tests/test_models.py, which runs under pytest. Results (n=20,000–25,000 per run):

eq1 / eq2corrtrue rhoestimated rhonotes
lognormal / lognormalTrue0.5000.508all regression coefficients within 2% of truth
probit / lognormalTrue-0.400-0.387
pgompertz / pgompertzTrue0.3500.3452 nodes each side; all 8 location/slope parameters within 1-4% of truth
lognormal / lognormalFalse0 (fixed)—coefficients recovered within 2-5% of the true (uncorrelated) data-generating values
The optimizer (scipy.optimize.minimize) can occasionally propose wild trial parameter values during its search — e.g. an exploding piecewise-Gompertz slope — which overflow into inf/nan and would otherwise crash the bivariate-normal-CDF call or corrupt the objective. fit_lillardhaz() guards against this with a _BAD_PENALTY finite-penalty wrapper around the log-likelihood (the same pattern used in the companion splitpopsurv package's Python port), and defaults to method="L-BFGS-B" rather than plain "BFGS", which was found more reliable for these likelihoods.

9. Examples

import numpy as np
from lillardhaz import fit_lillardhaz

# Probit & log-normal hazard, correlated
fit = fit_lillardhaz(
    "probit", "lognormal", data,
    y1="y1", y2="time2", d2="event2",
    x1=["x1"], x2=["x2"],
)
print(fit)
fit.rho, fit.rho_se

# Piecewise Gompertz & piecewise Gompertz, correlated, 2 nodes each side
fit = fit_lillardhaz(
    "pgompertz", "pgompertz", data,
    y1="time1", d1="event1", y2="time2", d2="event2",
    x1=["x1"], x2=["x2"], nodes1=[5], nodes2=[4],
)

# Same, but independent (nested test of rho = 0)
fit0 = fit_lillardhaz(
    "pgompertz", "pgompertz", data,
    y1="time1", d1="event1", y2="time2", d2="event2",
    x1=["x1"], x2=["x2"], nodes1=[5], nodes2=[4], corr=False,
)
lr_stat = 2 * (fit.loglik - fit0.loglik)   # ~chisq(1) under rho = 0

# Predictions
fit.predict(data, kind="surv2")
fit.predict(data, kind="dens2")
fit.predict(data, kind="xb1")
